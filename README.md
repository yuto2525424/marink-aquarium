# MARINK AQUARIUM ― 運命の館長

「自分だけの水族館を制作しよう！」
あなたの10の決断が、水族館の未来を変える。究極の三択 × 水族館経営 × マルチエンディングのWebゲームです。

- 全10問・各3択（選択の組み合わせは 3^10 = 59,049 通り）
- プレイ時間 約3〜5分／スマホ・PC対応／ログイン不要
- エンディング51種類（ハッピー・ビター・メリーバッド・トゥルー・シークレット・ギャグ・ループなど18タイプ）。同じエンディングでも、水族館の名前・イラスト・物語は選択によって変わります
- 総合評価はS・A・B・C・D・E・Fの7段階。結末と最終ステータスに応じて、水族館のイラストが「ぴかぴか」から「廃墟」まで11段階で変化
- 結果画像（1080×1350 PNG）の保存、SNS共有、結果URLの共有
- AI（Claude）による物語生成は **任意**。設定しなくても最後まで遊べます

## 1. GitHub で公開する手順（GitHub Pages）

このフォルダの中身は HTML / CSS / JavaScript だけで、ビルド（変換作業）は要りません。

1. GitHub にログインし、右上の「＋」→「New repository」を選びます
2. Repository name に `marink-aquarium` などを入力し、**Public** を選んで「Create repository」を押します
3. 作成された画面の「uploading an existing file」をクリックします
4. このフォルダ（`marink-aquarium`）の **中身すべて**（`index.html`、`css`、`js`、`assets` などのフォルダ）をドラッグ＆ドロップします
   - `index.html` がリポジトリのいちばん上の階層に来るようにしてください
5. 下の「Commit changes」を押します
6. リポジトリの「Settings」→ 左メニュー「Pages」を開きます
7. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main** と **/(root)** にして「Save」を押します
8. 1〜2分待つと、`https://あなたのユーザー名.github.io/marink-aquarium/` で誰でも遊べるようになります

> ファイルを更新したときは、同じファイルをもう一度アップロードして「Commit changes」を押すだけで反映されます。

## 2. パソコンで遊んでみる

- いちばん簡単な方法：`index.html` をダブルクリックしてブラウザで開く
- サーバーで確認したい場合（Node.js が必要）：

```bash
node tools/serve.js
```

ブラウザで `http://localhost:8080` を開きます。

## 3. テスト

```bash
node tests/run-tests.js
```

全59,049通りの選択を自動で最後まで進め、次のことを確認します（約10秒）。

- すべて10ラウンドで完結し、各ラウンドに3択がある（途中状態も抜き取り確認）
- 不正な選択履歴を受け付けない
- 資金の計算が1ステップずつ正しい／指標が0〜100に収まる／借入金が決算で処理される
- エンディングが必ず決まり、51種類すべてに到達できる
- 結末と状態が矛盾しない（赤字なのに成功エンドにならない、など）
- 設備がないのにジンベエザメを飼っていることにならない
- テンプレート物語に、選んでいない展示の描写や未定義の値が出ない
- 結果IDが59,049通りすべてで異なる／同じ選択なら同じ結果になる

## 5. AIモード（任意・有料）

GitHub Pages は静的なファイルしか置けないため、APIキーを安全に扱えません。
AIで物語を作る場合は、`server/` のサーバーを **Cloudflare Workers** などに別途公開します。

**ブラウザ側のファイル（`js/config.js` など）にAPIキーを絶対に書かないでください。** 誰でも見られてしまいます。

### 必要なもの
- Claude API のアカウントとAPIキー（https://platform.claude.com/ で作成。利用には支払い設定が必要です）
- Cloudflare のアカウント（Workers の無料枠あり）
- Node.js

### 手順
1. `server/wrangler.toml` の `ALLOWED_ORIGINS` を `https://あなたのユーザー名.github.io` に書き換える
2. ターミナルで次を実行

```bash
cd server
```

```bash
npm install
```

```bash
npx wrangler login
```

```bash
npx wrangler kv namespace create RATE_KV
```

3. 表示された `id` を `wrangler.toml` の `[[kv_namespaces]]` に書き、コメント（#）を外す
4. APIキーをサーバーの秘密情報として登録

```bash
npx wrangler secret put ANTHROPIC_API_KEY
```

5. 公開

```bash
npx wrangler deploy
```

6. 表示されたURLの末尾に `/story` をつけて、`js/config.js` の `aiEndpoint` に入れ、GitHub に再アップロード

### 安全対策（実装済み）
- APIキーはサーバーの環境変数のみ
- ブラウザからは選択履歴（10文字）だけを受け取り、数値とエンディングはサーバーで再計算
- 許可したサイト（ALLOWED_ORIGINS）以外からの呼び出しを拒否
- 回数制限：同じIPで10分に5回、1日10回、全体で1日300回（`wrangler.toml` で変更可）
- 同じ選択履歴の物語は30日間キャッシュし、AIを呼び直さない
- AIの応答は文字数・形式・内容（飼っていない生き物、結末との矛盾など）を検証し、ダメならテンプレートに切り替え
- 共有URLから開いた結果ではAIを呼ばない
- タイムアウト（20秒）やエラー時もゲームは止まらず、テンプレート物語を表示

### 料金の目安
- 使用モデル：`claude-opus-5-5`（入力 $4 / 出力 $20 ／100万トークンあたり。2026年11月時点）
- 1回の物語生成：入力 約3,000トークン、出力 約1,500〜3,000トークン → **約 $0.04〜0.07（6〜11円程度）**
- 1日の上限300回なら、最大で1日 約 $12〜21
- 料金はAnthropicの公式ページで必ず最新を確認してください。Claude Console で月の利用上限を設定しておくと安心です
- `CLAUDE_MODEL` を変えればより安いモデルにもできます（文章の質とのバランスは要確認）

> AIサーバーは、モックを使った自動テスト（`cd server && npm install && npm test`）で動作を確認済みですが、実際のClaude APIへの接続は、APIキーがないため未確認です。
